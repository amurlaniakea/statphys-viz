Modelo de Ising 2D

Simulación Monte Carlo interactiva de una transición de fase, comparada con la solución exacta de Onsager. Todo se calcula en tu navegador y puedes descargar los datos para verificarlos.

Qué estás viendo

  • Cada celda es un espín: naranja = +1, azul = −1. La red es de 64×64 con bordes periódicos.
  • Temperatura T (unidades J/kB): a T baja los espines se alinean y se forman dominios grandes. A T alta domina el desorden. Cerca de Tc ≈ 2.269 aparecen fluctuaciones a todas las escalas.
  • e/espín: energía por espín (−2 en el orden total, cerca de 0 en el desorden). |m|: magnetización absoluta por espín (1 = todos alineados, ≈0 = desordenado).
  • Wolff voltea clusters enteros y no sufre ralentización crítica. Metropolis voltea espines sueltos y cerca de Tc converge muy despacio: compáralos.

Teoría y fórmulas

Modelo, algoritmos y observables
  • Hamiltoniano: H = −J Σ⟨ij⟩ si sj, con si = ±1 y vecinos más próximos. Aquí J = kB = 1 y β = 1/T. Probabilidad de Boltzmann: P(s) ∝ e−βH.
  • Metropolis (1953): se voltea un espín con probabilidad min(1, e−βΔE), con ΔE = 2J si Σvecinos sj.
  • Wolff (1989): se crece un cluster de espines iguales añadiendo vecinos con probabilidad p = 1 − e−2βJ y se voltea entero. Solo es válido sin campo externo (h = 0).
  • Observables por espín: e = ⟨E⟩/N, m = ⟨|M|⟩/N, calor específico C = N β² (⟨e²⟩ − ⟨e⟩²) y susceptibilidad χ = N β (⟨m²⟩ − ⟨|m|⟩²), con N = L².
  • Cumulante de Binder: U4 = 1 − ⟨m⁴⟩ / (3⟨m²⟩²). Las curvas de distintos L se cruzan en Tc.
Solución exacta de Onsager (L → ∞)
  • Temperatura crítica: Tc = 2J / ln(1 + √2) ≈ 2.26919.
  • Magnetización espontánea (T < Tc): m = (1 − sinh−4(2βJ))1/8; vale 0 para T > Tc.
  • Energía por espín: u = −J coth(2βJ) [1 + (2/π)(2 tanh²(2βJ) − 1) K(κ)], con κ = 2 sinh(2βJ) / cosh²(2βJ) y K la integral elíptica completa de primera especie (de módulo κ). En Tc, u = −√2.
  • Calor específico: C = du/dT, con divergencia logarítmica en Tc.
Exponentes críticos y tamaño finito
  • Cerca de Tc: m ∼ |T − Tc|β con β = 1/8, χ ∼ |T − Tc|−γ con γ = 7/4, longitud de correlación ξ ∼ |T − Tc|−ν con ν = 1, y C con α = 0 (logarítmico).
  • En Tc y tamaño finito: m ∼ L−β/ν = L−1/8 y χ ∼ Lγ/ν = L7/4. Por eso con L finito los picos se redondean y |m| no cae exactamente a 0 por encima de Tc.
