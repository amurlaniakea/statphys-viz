statphys-viz
============

Visualización interactiva y **verificada** del modelo de Ising 2D para enseñar física estadística:
Monte Carlo (Metropolis y Wolff), comparación cuantitativa con la solución exacta de Onsager,
widgets de Jupyter y una demo web que corre en el navegador sin instalar nada.

* **Demo en vivo:** https://amurlaniakea.github.io/statphys-viz/
* **Código fuente:** https://github.com/amurlaniakea/statphys-viz
* **DOI (todas las versiones):** `10.5281/zenodo.24389055 <https://doi.org/10.5281/zenodo.24389055>`_
